# 情侣约会邀请网页

基于 https://github.com/ivysone/Will-you-be-my-Valentine- 二次开发，保留原 HTML/CSS/JavaScript 结构、按钮交互和原 GIF。原 MIT 许可证及 Copyright (c) 2025 ivysone 保留在 LICENSE 中。原 README 保存在 README.upstream.md。

## 配置

用文本编辑器打开 config.js，只修改 formEndpoint 的单引号内内容。示例：

    formEndpoint: 'https://formsubmit.co/ajax/你的QQ邮箱',

times 可修改预约时间，必须是 24 小时制 HH:mm。默认上海时区，预约当天；已到达的时间不可选择。所有时间判断依赖访问者设备时钟准确。

## FormSubmit 与 QQ 邮箱

1. 无需注册。在 config.js 中把 formEndpoint 设置为 https://formsubmit.co/ajax/你的QQ邮箱，保留 emailActivated: false。
2. 本地 HTTP 预览中点 No → Really no → Send my no，发送一条设置请求。这会向 FormSubmit 分享收件邮箱和测试记录。
3. 检查 QQ 收件箱、垃圾箱里的 FormSubmit 激活邮件，点击激活。不要把邮件里的管理密钥公开。
4. 完成激活后将 emailActivated 改成 true。可用激活邮件提供的随机标识替换 Endpoint 里的邮箱部分（保留 /ajax/）。
5. 分别测试接受和拒绝，确认 QQ 实际到信。每次用新的隐私浏览会话解除当天重复保护。
6. 激活邮件未到或提交失败时，不要公开发给对方；先核实 QQ 邮箱拦截和网络。免费服务可用性需实际测试。

不需要 QQ 密码或 SMTP 授权码。Endpoint 是公开的表单接收地址。成功页仅在 FormSubmit 返回成功后显示；这代表已接收，不代表邮件一定已投递。

提交字段：accepted（yes/no）、appointment_date、appointment_time（拒绝为空）、submitted_at（UTC ISO 时间）、time_zone、submission_id。

提交中禁用按钮；同一标签页会话中，当天成功后阻止重复提交。浏览器刷新、跨标签页或清除存储无法保证全局去重。断网或超时可能出现服务已收到但浏览器未收到确认的情况；重试前建议核实。无服务器方案不能保证严格一次提交。

## 本地预览

在此文件夹运行 python3 -m http.server 8000，然后浏览器访问 http://localhost:8000 。不要直接双击 HTML 测试提交。

## GitHub Pages（公开发布前需确认）

1. 在自己的 GitHub 账户创建公开仓库，上传本文件夹内网页、脚本、样式、assets 文件夹、LICENSE 和说明。不要上传密码。
2. 仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。
3. 等待部署完成后访问 GitHub 提供的 https://用户名.github.io/仓库名/，启用 Enforce HTTPS。
4. 用 iPhone Safari 打开链接，测试按钮、当天时间、GIF 和实际收信，再把链接发给对方。

网页、代码和 Endpoint 会公开；预约记录由 FormSubmit 接收，不写回 GitHub。无需域名、服务器、数据库或登录。国内网络访问 GitHub Pages / FormSubmit 的可用性需要实际检查。
